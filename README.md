# Inspecting-Electric-Vehicle-Changing-Trends
- Data Analysis Project using Power BI and Python - Jupyter notebook

- Designed an interactive Power BI dashboard to analyze EV charging behavior, costs, and performance metrics. Implemented KPIs, advanced visuals, and slicers for user segmentation, enabling data-driven insights and optimized charging station planning.

## Features

- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Visualization of key metrics such as charging duration, start time, and energy consumption
- Identification of peak usage periods and trends
- Analysis of geographical distribution of charging sessions

## Technologies Used
  
- Power BI
- DAX
- Python
- Pandas for data manipulation
- Matplotlib and Seaborn for data visualization
- Jupyter Notebook for interactive analysis

## Data Source
 
- The dataset for EV charging patterns is used for the analysis and is preprocessed for better insights.

## Key Insights – Benefits – Future Scope

1.	Evening Charging:
Most people charge in the evening → plan more chargers or lower prices at that time.
2.	Day Trends:
Wednesday busiest → plan maintenance on low-use days.
3.	Charger Type Matters:
Fast chargers charge quicker → invest more in fast-charging stations.
4.	Vehicle Model:
Charging speed not linked to car model → focus on charger quality, not car type.
5.	User Behavior:
Office commuters charge more on weekdays → place chargers near offices or highways.
6.	Cost:
Evening charging costs more → offer discounts or smart pricing.
7.	Vehicle Age:
New cars travel more → shows better battery efficiency.
8.	Fast Charger & Distance:
Fast chargers help drive longer → good for long-distance routes.
9.	Temperature:
Older cars charge hotter → monitor for battery safety.
10.	Cost by Charger Type:
Fast chargers are costlier → use for emergencies, slow ones for daily use.


## KEY FEATURES 
1. Business Problem:
The company wanted to understand how EV charging stations were being used because they faced issues like uneven charger usage, long wait times, and difficulty planning new stations.

2. Goal:
My goal was to analyze EV charging data and create a dashboard that clearly shows peak usage times, station performance, and user behavior to support better decision-making.

4. Key Visuals:
I included visuals like total sessions, energy consumption cards, peak charging hours, station-wise utilization, average charging duration, and location-based performance.

5. Business Impact:
These insights help optimize station placement, reduce wait times, improve customer satisfaction, support energy planning, and cut costs by investing only in high-demand areas.
